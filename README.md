# Quiet Vault

本地优先的密码保险库 MVP。React + TypeScript + Vite 静态前端，无账号、无 API、无默认云同步。桌面侧边栏与手机触控布局，支持分类和密码条目的增删改查，以及加密文件导入、导出。

## 运行

需要 Node.js 22.12+ 与 npm（首次安装需要访问 npm registry）：

```sh
npm install
npm run dev
```

浏览器打开终端输出的 localhost 地址。生产构建采用 Vite 默认的拆分方式，生成 `dist/index.html` 和 `dist/assets/` 中的脚本、样式：

```sh
npm run build
npm run preview -- --host 127.0.0.1
```

跨设备传输时请复制完整的 `dist/` 文件夹，保持目录结构，并通过 HTTPS 或本机静态文件服务访问。直接双击 `index.html` 不受支持。当前项目没有 Service Worker 离线缓存。

可将 `dist/` 部署到任意可信 HTTPS 静态站点，包括 Vercel。不要将备份文件放入 `public/`、源码仓库或部署产物。仓库忽略 `quiet-vault-*.json`、`*.qvault` 和 `.env*`。应用不包含 GitHub Token，也不提供上传功能。

## 使用与保存

1. 首次创建保险库时，主密码至少 12 位，且必须同时包含大写字母、小写字母和数字；建议使用独有的长口令。没有找回或重置功能。
2. 通过侧边栏的「新建分类」创建分类，通过「管理分类」查看、编辑或删除分类；分类可搜索，也可为分类挑选自定义图标或点击「随机」换一个；图标随分类一起加密保存。通过「新增密码」添加条目。条目按名称、账号或分类名搜索（不搜索密码）。按住条目左侧头像拖到分类上即可归类，手机端拖拽时会显示底部归类托盘。删除分类会把条目移至「未分类」。条目列表的复制按钮会把名称、账号、密码和备注一起复制到剪贴板；编辑弹窗中的复制按钮只复制密码。
3. 每次修改先加密，再写入此站点此浏览器的 localStorage。保存失败会显示错误，表单不会关闭。只有成功写入才更新应用状态。
4. 点击「导出备份」下载 `.json` 加密文件（文件名含本地时间）；需要在浏览器下载列表或手机「文件」中确认下载已完成。导出是另存为新版本，不会覆盖原文件。
5. 「导入」选择文件并输入该文件的主密码。成功解密、验证且确认替换后，才写入本地。不会合并保险库；导入前先导出当前版本。错误密码、损坏文件不会覆盖已有数据。
6. 只有主动点击「锁定」才会锁定，任一标签页锁定会同步锁定其他已打开的标签页。刷新页面、关闭后重开、闲置或切到后台都不会要求重新输入主密码。其他标签页改变保险库时，当前页面会自动加载最新版本；如果其他标签页导入了不同的保险库，则需要输入该文件的主密码。写入使用 Web Locks 对版本检查和保存加锁，防止两个标签页同时覆盖；不支持 Web Locks 的旧浏览器会拒绝保存，请升级浏览器。

## 备份与手动同步

浏览器存储可能因清理、隐私模式、卸载、设备丢失而消失，**本地自动保存不等于备份**。请定期导出，并保留多份带日期的历史版本。首次导出后，建议在另一个浏览器验证可以导入解锁。

跨设备：设备 A 导出 → 通过你信任的文件传输、私有网盘或系统文件同步工具传送 `.json` 备份 → 设备 B 导入。应用不会公开上传密文，也不读取其他设备的更改。并行修改不会自动合并，请约定一份权威版本，覆盖前分别备份。密文虽加密，仍应私密保存，避免给攻击者离线猜测主密码的机会。

## 手机浏览器

使用现代 iOS Safari / Android Chrome，通过可信的 **HTTPS** 地址访问静态应用，再从「文件」选择备份导入；手机控件和弹窗支持触摸，分类在顶部横向滚动，右上角「分类」可管理。

桌面 `localhost` 可使用 Web Crypto；手机访问电脑的普通 `http://局域网IP` 通常不是安全上下文，无法使用 Web Crypto，应使用可信证书的 HTTPS 静态部署或 HTTPS 局域网服务。直接双击 `index.html` 不可运行。应用没有 service worker，未承诺关闭后离线重开；已加载的页面可在断网时编辑，数据持久化不依赖网络。可将站点添加到主屏幕作为快捷入口，但它不是完整离线 PWA。

切换到「文件」或其他 App 不会锁定保险库，也不会丢弃已加密保存的数据；把设备交给他人前请主动点击「锁定」。

## 安全设计与边界

- 主密码只用于浏览器内 Argon2id 派生 32 字节密钥：64 MiB 内存、3 次迭代、并行度 1，随机 16 字节 salt。通过 `hash-wasm` 本地 WASM 实现，不请求 CDN。
- 使用 Web Crypto 的 AES-256-GCM，128 位认证标签；每次保存生成全新随机 12 字节 IV，认证附加数据为 `quiet-vault:1`。salt 在同一保险库内保持不变；创建新保险库使用新 salt。
- 派生后的 CryptoKey 不可导出。为支持刷新后免密恢复，该 CryptoKey 通过结构化克隆保存在 IndexedDB 中，仍然不可导出，脚本无法读出原始密钥字节；手动「锁定」时删除。主密码、原始密钥字节和明文从不写入 localStorage、sessionStorage 或 IndexedDB。分类、名称、账号和密码同样加密。派生原始密钥字节和临时明文字节在使用后清零。
- 文件包含公开的格式版本、固定 KDF 参数、salt、IV 和密文。导入限制 5 MiB 并拒绝未知参数，避免任意 KDF 内存/计算开销。GCM 验证可检测篡改，错误密码与损坏密文统一报错。
- 无服务端加解密、遥测、第三方字体或远程图标。分类图标来自本地打包的 Iconify Lucide 图标集，运行时不会请求图标 CDN。Vercel/静态主机只托管代码；正常运行不接收主密码和密码数据，但会接收普通静态资源请求及其访问元数据。
- 静态主机如果被攻陷，可以投递恶意 JavaScript；恶意扩展、XSS、被入侵的设备、屏幕录制、剪贴板工具也能窃取解锁后的内容。建议自托管可信构建，使用干净且更新的浏览器。页面包含限制脚本和连接来源的 CSP；生产托管还应配置 HTTP 安全响应头。
- 免密恢复意味着同一浏览器配置下运行的脚本（XSS、恶意扩展、被入侵的设备）可以在没有主密码的情况下使用 IndexedDB 中的会话密钥；请像保护已解锁的会话一样保护浏览器配置。JS 字符串和 React 状态无法保证物理内存彻底擦除，锁定仅丢弃应用引用并删除会话密钥；不是经过独立安全审计的成熟密码管理器。主密码强度决定离线攻击成本。64 MiB KDF 在低端手机上可能较慢。
- 复制条目会写入系统剪贴板；浏览器不能可靠保证定时清除系统剪贴板，使用后请自行清理。名称和账号仅作为文本存储，不会自动打开链接或请求网站图标。
- 不支持主密码修改、恢复密钥、自动填充、多人协作、自动合并、硬件密钥或云端同步。

## 测试

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

单元测试涵盖真实 Argon2id/AES-GCM 往返、salt/IV 随机性、错误密码、密文篡改、格式/参数/大小限制、明文结构校验及主密码强度规则。E2E 覆盖桌面和手机视口的分类/条目 CRUD、过滤、搜索、持久化、刷新与闲置保持解锁、手动锁定、备份导入导出、损坏文件保留数据、主密码强度校验与主题切换。

验证记录与环境限制见 `REVIEW.md`。

参考：[hash-wasm](https://github.com/Daninet/hash-wasm)、[Web Crypto AES-GCM](https://developer.mozilla.org/en-US/docs/Web/API/AesGcmParams)。
